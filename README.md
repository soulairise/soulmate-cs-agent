# 소울매트 고객응대 에이전트

요가 브랜드 **소울매트**의 고객 문의를 분류하고, 어드민을 조회해 답하고,
내보내기 전에 한 번 더 점검하는 LangGraph 에이전트.

AIFFEL AI 에이전트 1기 「고객 응대 에이전트」 노드 실습작. 교안의 모두몰 예제를 읽고,
소울매트의 실제 업무에 맞춰 다시 설계했다.

## 모두몰 예제와 무엇이 다른가

소울매트는 **물건도 팔고 수업도 연다.** 이 한 가지 차이가 설계 전체를 바꿨다.

| | 모두몰 (교안) | 소울매트 |
|---|---|---|
| 라우트 | 5개 | **6개** — `CLASS_BOOKING` 추가 |
| 도구 | 9개 | **12개** — 수업 축 3개 추가 |
| 가드레일 | 숫자 출처 1가지 | **4가지** — 숫자 + 건강 단정 + 효능 표현 + 미확정 값 확답 |
| 지표 | ② 2개 | **3개** — ③ 안전 점검 추가 |

### 왜 가드레일을 늘렸나

요가 브랜드에서 제일 위험한 답변은 틀린 숫자가 아니다.

> 고객: "허리 디스크가 있는데 아쉬탕가 해도 될까요?"
> 에이전트: "네, 무리 없이 하실 수 있습니다."

이 한 줄이 나가는 순간 소울매트가 책임을 진다. 그래서 건강·의료 문의는
**분류 정확도와 무관하게** 사람에게 넘어가도록 세 겹으로 막았다 —
매뉴얼 7.2, `ANSWER_RULES` 7번, 그리고 가드레일의 `건강 판단 단정` 점검.

같은 이유로 "교정된다 / 낫는다 / 살이 빠진다" 같은 효능 표현도 막는다(표시광고법).

## 구조

```
route → answer → guard → (END | answer 재시도 | escalate)
```

| 파일 | 하는 일 |
|---|---|
| `src/prompts.py` | **성능에 가장 크게 영향을 준다.** 라우팅 지침과 답변 규칙 |
| `src/config.py` | 모델·임계값·라우트 목록 |
| `src/router.py` | ① 분류(LLM) + ② 판정(정책). 둘을 나눠 임계값만 바꿀 땐 모델을 안 부른다 |
| `src/tools.py` | 어드민 조회 12종. 매뉴얼의 `[어드민 조회]` 표시에서 도출 |
| `src/context.py` | 매뉴얼을 장 단위로 쪼개 라우트에 필요한 장만 붙인다 |
| `src/answer.py` | 모델이 스스로 도구를 골라 부르는 그래프 |
| `src/guardrail.py` | 내보내기 전 4가지 점검 |
| `src/agent.py` | 위를 하나로 잇는다 |
| `src/evaluate.py` | 세 지표를 잰다. `--repeat N` 으로 반복 측정 |
| `src/chat.py` | 터미널에서 직접 말 걸어 보기 |

## 돌려보기

```bash
uv venv && uv pip install -r requirements.txt
export OPENAI_API_KEY=...        # 키는 저장소에 넣지 않는다
cd src && python evaluate.py --repeat 3
```

```bash
./run.sh              # 직접 대화 (키는 ~/.config/harness-lab/env 에서 읽는다)
./run.sh eval --repeat 3
```

**만들면 반드시 직접 말을 걸어 볼 것.** 지표 세 개가 전부 통과하는데도 대화에서는
앞 턴 답을 통째로 다시 말하는 결함이 있었다. 한 턴짜리 평가로는 안 잡힌다.

## ⚠️ 실제 고객에게 쓰기 전에

`data/policy_soulmate.md` 부록 B 에 **`[임시]` 로 채워 둔 9개 항목**이 있다.
업계 통상값으로 자리만 잡아 둔 것이지 소울매트가 정한 값이 아니다.
그중 **7번(수업 취소·환불 규정)** 이 가장 급하다 — 돈이 오가는 약속이라 틀리면 분쟁이 된다.

지금은 에이전트가 이 값들을 확답하지 않도록 가드레일이 막고 있다(`임시값 확답` 점검).
대표님이 확정해 주시면 `[확정]` 으로 바꾸고 `src/context.py` 의
`PROVISIONAL_POLICY` → `CONFIRMED_POLICY` 로 옮기면 된다.
